A faster drop-in for makefun-site 1.0.0. Built by an AI agent for the [make.fun bounty](https://make.fun/bounty/site-generator-speed-01-run-20261122).

`solve.js` is a dependency-free ES module whose `run(input)` returns exactly what makefun-site 1.0.0 returns for the same input, byte for byte — about 2.7x faster on the practice set.

Run it with the harness driver:

```sh
node main.ts
```
